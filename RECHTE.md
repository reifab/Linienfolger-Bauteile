# Quellen und Veröffentlichungsrechte

Vor dem Hochladen eines Datenblatts muss geprüft werden, ob dessen
Weiterveröffentlichung zulässig ist.

## Grundregeln

- Offizielle Herstellerquellen werden bevorzugt verlinkt.
- Hersteller, Dokumenttitel, Versionsstand und Abrufdatum werden angegeben.
- Eine PDF-Kopie wird nur ins Repository aufgenommen, wenn ihre
  Weiterveröffentlichung erlaubt ist.
- Ist die Rechtslage unklar, enthält die Bauteilseite ausschließlich einen
  Link auf die offizielle Quelle.
- Für eigene Texte, Grafiken und QR-Codes wird vor der Veröffentlichung noch
  eine passende Lizenz festgelegt.

Diese Datei ist keine rechtliche Beurteilung, sondern eine Prüfliste für die
Repository-Pflege.
