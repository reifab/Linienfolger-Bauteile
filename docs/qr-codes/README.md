# QR-Codes

Die QR-Codes werden später aus den veröffentlichten Adressen der Bauteilseiten
erzeugt.

QR-Codes sollen auf eine Bauteilseite unter `docs/bauteile/` und nicht direkt
auf eine PDF-Datei zeigen. Dadurch kann das verlinkte Datenblatt ausgetauscht
werden, ohne den gedruckten QR-Code zu ändern.
