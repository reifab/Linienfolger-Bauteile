# Datenblätter

In diesem Ordner werden nur PDF-Dateien abgelegt, deren Veröffentlichung im
Repository zulässig ist.

Für jedes Datenblatt müssen auf der zugehörigen Bauteilseite mindestens Quelle,
Hersteller, Dokumentversion und Abrufdatum angegeben werden.

Die bereits gefundenen Originaldokumente und ihr Prüfstatus stehen im
[Quellenregister](quellen.html).
